# Raen Browser

Your feeds, videos, music and friends in one calm place: a desktop app for Windows.

This repository holds the installers and updates only.

## Install

Open [Releases](../../releases), download `Raen-Browser-Setup-<version>.exe` from the newest one and run it.
Windows may warn that the publisher is unknown: choose **More info**, then **Run anyway**.
Once installed, Raen Browser updates itself.
